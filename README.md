## Online Rubik's Cube Simulator

## Overview

This project was developed as part of my A-Level Computer Science NEA using Unity and C#. The aim was to create an interactive Rubik's Cube which accurately shows the cube's state and user's can make face rotations based on their mouse input.

The project provided me with practical experience in OOP, algorithm design and managing complex data structures to represent the cube.


## Features

- Interactive 3D Rubik's Cube built in Unity
- Accurate face rotation mechanics
- Representation of the cube's state
- User input changes the cubes state
- Modular object - oriented code structure


## Technologies Used

- C#
- Unity
- VScode


## Skills Demonstrated

- Object - Oriented Programming (OOP)

- Software Development

## What I Learned

Through this project I developed a stronger understanding of software design and object-oriented programming. I gained experience implementing algorithms, managing the state of complex systems as well as debugging larger codebases within the Unity game engine.
